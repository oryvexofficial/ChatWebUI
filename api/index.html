شروع سریع

آدرس روتر (Base URL) و کلید عمومی (public_api_key) را از api/links.json یا صفحه‌ی Public API Key بگیر و مثل 9router / OpenAI استفاده کن.

# 1) Fetch live Base URL & Backend-Generated API Key
LINKS=$(curl -s http://local.test:18087/pages/api/links.json)
BASE=$(echo "$LINKS" | jq -r .base_url)
KEY=$(echo "$LINKS" | jq -r .public_api_key)

# 2) Call OpenAI-compatible Router (/v1/chat/completions)
curl -X POST "$BASE/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $KEY" \
  -d '{"model":"Unicollect Chat Mini","messages":[{"role":"user","content":"سلام! خوبی؟"}]}'

HTTPcodeیعنی

کتابخانه‌ها

نیاز به کتابخانه‌ی خاصی نیست؛ هم با HTTP معمولی کار می‌کند و هم با openai رسمی از طریق /api/v1/chat/completions.

import requests

PAGES = "http://local.test:18087/pages/api/links.json"
BASE = requests.get(PAGES, timeout=10).json()["base_url"]

r = requests.post(f"{BASE}/api/v1/chat", json={"message": "یک شعر کوتاه بگو"})
print(r.json()["reply"])
