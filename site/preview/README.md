# OryvexVPN visual preview

This static HTML, CSS and JavaScript preview is an interactive illustration based on the Flutter app source. It is not the app and does not create a real VPN or proxy connection, sign in, install a certificate, deploy a relay, access an account, measure real network traffic or retrieve real network locations. Status, activity and locations are simulated examples. No credentials are collected. It shows Windows and Android settings together for exploration; the real app varies by platform, route and state.

Run `python3 -m http.server --directory site 8000` from the project root, then visit `http://localhost:8000/preview/`.
