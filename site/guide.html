Guide

Start in three minutes.

Install OryvexVPN, pick a route, and connect. Fox sign-in and personal Cloudflare relay deployment are covered step by step below.

Try the interface first. You can explore the interactive browser preview to test routes, country flags, live telemetry cards, and the Fox account modal before installing.

Install

  1. Open Downloads and grab the Windows x64 installer or the Android universal APK.
  2. On Android, allow installation when prompted. On Windows, run OryvexVPN-Setup.
  3. Open OryvexVPN, select a route in the Route card, and press Connect. Once connected, the Connect panel and Gateway card display your active gateway and country flag.

Connect with Fox

  1. Choose Fox in the Route card.
  2. If you tap Connect before adding an account, OryvexVPN displays the Account Required for Fox modal with one-tap options to Create / Sign in with Mozilla or use Other sign-in (Email & Password).
  3. Once your Firefox Account is added, pick a country location (or Fastest) and press Connect.

Fox is an unofficial client and requires an eligible Firefox Account. On Android it can route the entire device via VPN mode; on Windows it provides a local SOCKS5 proxy and optional system proxy toggle.

Deploy your Fox relay

  1. Choose Fox, or open Settings → Fox connection → Deploy Cloudflare relay.
  2. Press Token Template. Cloudflare opens in your browser with Worker permissions pre-filled. Create the token and paste it into OryvexVPN.
  3. Select your Cloudflare account and press Deploy and configure Fox.

OryvexVPN uploads the bundled Worker, generates a random 40-character secret, enables its workers.dev subdomain, and saves the relay into Fox. The Cloudflare API token is never stored on disk.

Know what passes through. The relay forwards Fox authentication and control-plane calls only; general VPN traffic never goes through the Worker.

Locations & Flags

Tor and Fox allow you to choose specific exit countries with bundled high-contrast flags. For WireGuard, MASQUE, Gool, and Fox, OryvexVPN also displays the connected country and flag directly under the status headline and in the Gateway card.

If it gets stuck

Check the selected route and account, then try another route in the Route card. The Activity tab logs connection stages and errors without slowing down the interface. For Fox, run the relay health check in Settings after deploying.
