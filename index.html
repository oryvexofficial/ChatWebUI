مدل: یونیکالکت چت مینی سازنده: موویکسو باز کردن پنل زنده
روتر و کلید عمومی API

اتصال مستقیم با کلید عمومی و آدرس روتر.

  • نام مدل: یونیکالکت چت مینی (unicollect-chat-mini)
  • کلید عمومی API: sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26
  • آدرس پایه روتر: https://YOUR-LINK.trycloudflare.com/v1
  • فایل وضعیت زنده: api/links.json
صفحه‌ی کلید عمومی API 
curl -X POST https://YOUR-LINK.trycloudflare.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26" \
  -d '{"model": "unicollect-chat-mini", "messages": [{"role": "user", "content": "سلام! خوبی؟"}]}'
import requests

url = "https://YOUR-LINK.trycloudflare.com/v1/chat/completions"
headers = {"Authorization": "Bearer sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26"}
payload = {
    "model": "unicollect-chat-mini",
    "messages": [{"role": "user", "content": "سلام! خوبی؟"}]
}
print(requests.post(url, json=payload, headers=headers).json())
const res = await fetch("https://YOUR-LINK.trycloudflare.com/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26"
  },
  body: JSON.stringify({
    model: "unicollect-chat-mini",
    messages: [{ role: "user", content: "سلام! خوبی؟" }]
  })
});
console.log(await res.json());
