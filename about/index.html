درباره

دستیار هوشمند گفتگومحور با کلید عمومی رایگان.

پروژه‌ای مستقل از موویکسو با رابط کاربری یکدست فارسی و سیاه‌وسفید.

UNICOLLECT موویکسو BY MUVIXO

یونیکالکت چت مینی چیست؟

یونیکالکت چت مینی دستیار هوش مصنوعی گفتگومحور ساخته‌ی موویکسو است که برای پاسخ‌گویی روان به زبان فارسی و سایر زبان‌ها، نوشتن متن، خلاصه‌سازی، ترجمه، ایده‌پردازی و محاسبات دقیق طراحی شده است.

کلید عمومی API و روتر چگونه کار می‌کند؟

بک‌اند سرویس به‌صورت خودکار یک کلید عمومی (sk-uc-...) و آدرس روتر استاندارد (/v1/chat/completions) تولید و در صفحه‌ی کلید عمومی منتشر می‌کند تا بتوانید در هر برنامه یا روتر از آن استفاده کنید.

مشاهده‌ی کلید عمومی API

چطور از طریق API متصل شوم؟

با یک درخواست POST به مسیر /api/v1/chat یا /v1/chat/completions می‌توانید پاسخ مدل را دریافت کنید.
