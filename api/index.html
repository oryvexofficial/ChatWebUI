خطاها

همه‌ی خطاها یک ساختار استاندارد JSON با کد وضعیت HTTP مشخص برمی‌گردانند.

{
  "error": {
    "code": "empty_message",
    "message": "پیام خالی است",
    "status": 400
  }
}
HTTPکد خطاتوضیح
400empty_message · message_too_longپیام خالی یا بیش از حد مجاز است
401unauthorizedکلید نامعتبر است یا ارسال نشده
429rate_limitedتعداد درخواست بیش از سقف مجاز در دقیقه
502upstream_unavailableسرویس مدل در دسترس نیست
503not_readyمدل هنوز در حال بارگذاری است

کتابخانه‌ها و دریافت خودکار آدرس زنده

می‌توانید آدرس تونل فعال و کلید عمومی را به‌صورت خودکار از api/links.json دریافت کنید:

import requests

PAGES = "https://oryvexofficial.github.io/ChatWebUI/api/links.json"
info = requests.get(PAGES, timeout=10).json()
BASE = info["base_url"]
KEY = info.get("public_api_key", "sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26")

r = requests.post(
    f"{BASE}/api/v1/chat",
    headers={"X-API-Key": KEY},
    json={"message": "یک جمله‌ی کوتاه انگیزشی بگو"}
)
print(r.json()["reply"])
const info = await fetch("https://oryvexofficial.github.io/ChatWebUI/api/links.json").then(r => r.json());
const r = await fetch(`${info.base_url}/v1/chat/completions`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${info.public_api_key || "sk-uc-7222f6a12db36a017b3e3d6ac8a6dc26"}`
  },
  body: JSON.stringify({
    model: "unicollect-chat-mini",
    messages: [{ role: "user", content: "سلام!" }]
  })
});
console.log(await r.json());
